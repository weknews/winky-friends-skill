# kit/moments/ — 공감 장면 은행

대본의 출발점. **장면이 먼저, 지침은 나중이다.** 실제로 당뇨인과 가족이 겪는 작은 장면을 모아 두고, 대본은 여기서 장면 하나를 골라 시작한다. 그 장면에 자연스럽게 걸리는 지침 한 줄이 있을 때만 의학 이야기를 건다. 걸 지침이 없는 장면은 버리지 않고 여기서 기다린다.

- `bank.md`: 장면 묶음. 같은 상황이 여러 출처에 나오면 한 묶음이다(출처가 많을수록 흔한 장면).
- 원자료(수집한 글·댓글 원문, URL)는 레포에 두지 않는다. 출처는 종류만 적는다.

## 장면 한 칸

| 칸 | 뜻 |
|---|---|
| 상황 | 언제·어디서·누구와. 우리 말로 다시 쓴 한 줄 |
| 실제 말 | 출처에 있던 짧은 말(30자 이하). **화면에 그대로 쓰지 않는다.** 말투 참고용 |
| 감정 | 민망, 억울, 눈치, 귀찮음, 미안함, 답답, 뿌듯… |
| 웃픈 지점 | 이 장면이 웃기거나 짠한 이유 한 줄 |
| 출처 | 종류와 수(유튜브 댓글 3, 커뮤니티 2, 블로그 1, 논문 1) |
| 빌라에서 | 이 장면을 살 인물 후보(곰 아빠만 아니게, 둘 이상) |
| 지침 후보 | 걸릴 수도 있는 지침 주제. **추정**이다. 대본에서 원문으로 확인한다(`rules/guideline-gate.md`) |

## 더하는 법

1. 출처: 사내 수집 폼, 유튜브 당뇨 채널 댓글, 네이버 블로그, 커뮤니티 가족 글, 국내 질적 연구.
2. 이름·아이디·병원·지역을 지우고 상황을 다시 쓴다. 실제 말은 30자 이하로 자른다.
3. 기존 묶음에 맞으면 그 묶음의 출처 수를 올리고, 아니면 새 묶음을 연다.
4. 회차에 쓰이면 「쓰인 회차」에 적는다. 장부(`episodes/LEDGER.md`)와 같은 이름.

## 넣지 않는 것 (낙인·범위)

- 합병증, 실명, 쓰러짐, 죽음, 간병 공포: 웃음 소재가 아니다(`rules/world.md` 2절).
- 임신성 당뇨, 1형 당뇨, 아이 혈당: 세계관 범위 밖.
- **환자의 식탐·의지 부족을 웃음 과녁으로 삼는 틀**(「못 참는 어른」). 웃음은 가족의 작전, 엇갈린 사랑, 누구나 하는 핑계에서 나온다.
- 건강즙·유튜브를 믿는 부모를 바보로 그리는 틀. 과녁은 정보 홍수와 선물 문화다.
- 거짓말·들킴으로 읽히는 틀(몰래 먹다 걸림). 쓰려면 들키는 쪽이 아니라 숨겨 주는 쪽, 같이 먹는 쪽을 보여 준다(`rules/stigma.md`).
