# 「윙키와 친구들 · 모래언덕 빌라」 시리즈 로고 (2026-11-11, 시안)

> 이 레포로 옮겨 온 판: 쓰는 파일은 `kit/logo/logo-main.png`·`logo-inline.png`(레지스트리 `logo-main`·`logo-inline`). `make.py`·`papertext.py`·`gen_logo.sh`는 이전 제작 폴더 경로(`../ep01-v9/kit`, `gen/`, `cand/`) 기준 기록이라 여기서는 그대로 돌지 않는다.

시리즈 제목은 「윙키와 친구들」(크게), 부제는 「모래언덕 빌라」(작게)다(제작자 결정). 비교판은 `LOGO-REVIEW.png`.

## 쓰는 파일

| 파일 | 크기 | 쓰는 곳 |
|---|---|---|
| `logo-main.png` | 1484×777, 투명 | 큰 로고(가로형, 시안 A1). 썸네일 오른쪽 아래(폭 540), 영상 끝 화면 아래(폭 478) |
| `logo-inline.png` | 1486×320, 투명 | 한 줄형(시안 A3). 영상 첫 컷 위쪽(폭 900, 0.0~1.5초) |

영상 키트(`ep01-v9/kit/`)에도 같은 파일을 복사해 둔다(`make.py`가 함께 한다).

## 시안과 고른 이유

| 시안 | 방법 | 평 |
|---|---|---|
| **A1 가로형 (고름)** | Images 2.6이 글자까지 그림 | 남색 종이 글자 + 크림·흰 종이 겹 테두리가 한 그림 안에서 그려져 그림체가 가장 잘 맞는다. 윙키가 「윙」 위에서 손을 걸치고 있어 글자와 어우러진다. 폭 120px에서도 「윙키와 친구들」이 읽힌다 |
| A2 세로 스택형 | 같음 | 완성도는 A1과 같다. 정사각이라 프로필 그림·앱 아이콘 자리에 맞지만, 쇼츠 썸네일·영상 띠 자리에는 세로로 길어 큰 면을 차지한다 |
| B1 가로형 | 글자 없는 판(투명) + 도현·주아 글자를 래스터화해 종이 질감·겹 그림자를 입힘(`papertext.py`) | 글자 모양은 글꼴이라 확실하지만, 그림 위에 붙인 스티커처럼 떠 보이고 판이 길어 글자가 작다 |
| B2 세로 스택형 | 같음 | B1과 같은 문제. 판 안 여백이 커서 글자가 작다 |
| A3 한 줄형 | A1을 기준 그림으로 편집 | 첫 컷 위쪽(윙키 귀 위 좁은 띠)에 들어가는 높이. 윙키는 작은 귀만 남겼다 |
| A4 두 단 납작형 | A1 편집 | A1에서 윙키 얼굴을 귀로 줄인 판. 지금은 쓰는 곳이 없어 남겨만 둔다 |

- 글자 검수: A1·A2·A3·A4를 확대해 「윙키와 친구들」 「모래언덕 빌라」 열세 자를 한 자씩 봤다. 오탈자·빠진 획·이상한 획이 없다(A3·A4는 같은 글자를 다시 그렸으니 쓸 때마다 다시 본다).
- 색: 윙키 크림·분홍 귀·꼬리 끝 갈색(작게)과 남색 #10233F 글자, 모래색 띠. 빨강·보라·갈색 큰 면 없음. 윙키 노란 손짓 줄은 기준 그림에서 왔다.
- 생성 그림 둘레의 반투명 부스러기는 `make.py` `clean()`이 지운다(작은 떨어진 조각 제거).

## 만드는 순서

```bash
./run1.sh        # A1·A2(글자까지), B1·B2(빈 판) → gen/  (gen_logo.sh = series-kit/gen.sh와 같은 Codex image_gen 호출, 투명 배경)
./run2.sh        # A1을 기준으로 A3 한 줄형·A4 두 단 납작형
python3 make.py  # B 글자 합성 → cand/, LOGO-REVIEW.png, logo-main.png·logo-inline.png(+ ep01-v9/kit/)
```

## 한계

- 글자를 그림 모델이 그렸으므로 고칠 때(색·배치) 다시 생성해야 하고, 그때마다 글자를 다시 확대해 본다. 벡터 원본은 없다.
- A3 한 줄형의 작은 귀는 고양이 귀처럼도 보인다. 첫 컷에서 바로 아래 윙키 실제 귀가 같이 보여서 지금은 문제가 덜하다.
