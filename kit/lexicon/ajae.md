# 아재 개그 사전 (곰 아빠용)

곰 아빠는 몸 얘기가 나오거나 곤란하면 아재 개그부터 던진다(`rules/characters.md` 2번). 이 문서는 그 개그를 만드는 법과 재고 목록이다.

- 수집: 2026-11-12. 나무위키 「아재개그」(CC BY-NC-SA 2.0 KR), 블로그 정리글 2종(foxcg.com, 매일매일꿀팁). 원료 176개와 URL은 `skills/winky-script/references/R-25-ajae-raw.md`.
- 정리글 개그는 원저자를 알 수 없다. 재고 목록은 아이디어 창고로만 쓰고, 대사에는 우리 상황에 맞게 바꿔 쓴다.
- 「50대가 실제로 이 개그를 하나」를 잰 설문은 찾지 못했다. 마지막 판정은 소리 내 읽기다.

## 1. 제일 센 건 그 자리에서 만든 말장난

준비해 온 퀴즈보다 **방금 상대가 한 말을 받아서 비튼 것**이 훨씬 웃기다. 상황에 붙어 있어서 억지로 끼운 느낌이 없다.

| 상대 말 | 곰 아빠 | 비튼 방법 |
|---|---|---|
| 「다음. 분리수거.」 | 「허허허! 분리 수고하십니다!」 | 소리가 비슷한 말로 바꾸기 |
| 「누워 있었습니다.」 | 「허허허! 침대봉 찍었네!」 | 자기 소재(산)로 끌고 오기 |
| (잡곡밥이 고소하다) | 「허허허! 고소해서 고소하겠다!」 | 같은 소리, 다른 뜻 |
| 「자네는 2층에서 내리던데.」 | 「허허허! 거기가 종점입니다!」 | 자기 소재(버스)로 끌고 오기 |
| 「대박이야.」 | 「허허허! 쪽박만 아니면 됐다!」 | 반대말로 받기 |
| 엘리베이터 고장 | 「이번 정류장은~ 계단입니다~」 | 버스 안내 방송 틀에 넣기 |

### 만드는 법 다섯 가지

1. **소리 바꾸기:** 상대 말의 한 글자를 바꾼다(분리수거 → 분리 수고).
2. **같은 소리, 다른 뜻:** 한 낱말을 두 뜻으로 쓴다(고소하다: 맛 / 법).
3. **반대말로 받기:** 상대 말의 반대를 소리로 맞춘다(대박 → 쪽박, 물고기 → 불고기).
4. **내 소재로 끌고 오기:** 무슨 말이든 버스(정류장·종점·환승·배차)나 산(봉우리·정상·하산·능선)으로 바꾼다. 곰 아빠 개그가 다른 사람 개그와 갈리는 지점이다.
5. **안내 방송 틀:** 「이번 정류장은~ ○○입니다~」 「잠시 후 ○○, ○○입니다~」. 곰 아빠의 고정 개그다. 한 회에 한 번까지만 쓴다.

## 2. 박자

아재 개그는 개그보다 **그다음 반응**이 웃긴다.

1. 곰 아빠: 「허허허! (개그)」
2. `―` 정적 0.5초 안팎. 상대는 대사 없이 굳는다.
3. 다음 중 하나:
   - 상대가 무시하고 하던 말을 한다(거북 여사: 「2층, 페트병 안 씻었지.」)
   - 상대가 짧게 받는다(판다: 「아 진짜…」, 거북 여사: 「…집이잖아.」)
   - 곰 아빠가 혼자 한 번 더 웃는다
4. 안 먹히면 곰 아빠는 한 박자 쉬고 **다른 개그를 하나 더** 한다. 두 번째가 더 썰렁하면 그게 웃음이다.

## 3. 쓰지 않는 것

- **진료·약·수치에는 개그를 붙이지 않는다.** 아빠가 당뇨를 숨기는 걸 비웃는 꼴이 된다(`rules/characters.md` 곰 아빠 「조심할 것」).
- 당·병원 소재 말장난(포도당, 건강, 따끔합니다)은 곰 아빠 몸 얘기를 피하는 자리에서 쓰지 않는다. 쓴다면 남 얘기로만.
- 몸무게·체형·외모, 성적 농담, 나라·지역·민족, 정치·종교, 실존 인물 이름(우사인 볼트, 유재석 같은 것), 죽음·가난 개그. 수집 단계에서 뺀 것도 있고, 여기서 더 뺐다.
- 「~하는 순간은?」 같은 생활 공감 농담(버스는 편의점 들어간 직후에 온다 등)은 아재 개그가 아니다. 쓰려면 너구리 대리·판다 대사로(4절 끝).

## 4. 재고 (곰 아빠가 「문제 하나 낸다」 할 때)

퀴즈형은 곰 아빠가 「판다야, 문제 하나 낸다」 하고 먼저 꺼내는 장면에 쓴다. 대부분 정리글에서 왔다(【확인】 = 나무위키에서 봄).

**산**
- 물이 떨어지는 산은? → 수락산 【확인】
- 움직이지 않는 산은? → 부동산 【확인】
- 산이 놀라면? → 와우산 【확인】
- 세상에서 가장 잔인한 비빔밥은? → 산채비빔밥

**차·길**
- 세상에서 가장 긴 차는? → 기차
- 절대 안 움직이는 차는? → 주차
- 차는 차인데 못 타는 차는? → 홍차

**곰 자기 소재**
- 곰이 깊은 생각에 빠지면? → 곰곰이
- 아재 개그 듣고 제일 좋은 반응은? → 1초 정적 (판다가 그대로 해 준다)
- 아재 개그의 완성은? → 던진 사람이 제일 크게 웃기

**밥상**
- 물고기의 반대말은? → 불고기 【확인】
- 전주비빔밥의 반대말은? → 이번 주 비빔밥
- 참기름이 화나면? → 고소해
- 부침개가 화나면? → 뒤집는다
- 찌개가 화나면? → 끓어오른다
- 콩이 화나면? → 콩가루 집안
- 파가 화나면? → 파김치
- 고구마가 군대 가면? → 군고구마
- 떡이 넘어지면? → 떡볶이
- 우유가 결정을 못 하면? → 우유부단
- 소는 소인데 먹는 소는? → 채소
- 초는 초인데 불 안 붙는 초는? → 식초
- 금 중에 제일 짠 금은? → 소금
- 세상에서 가장 무서운 밥은? → 콩밥

**날씨**
- 미국에 비가 내리면? → USB
- 해 났는데 비 오면? → 여우비
- 세상에서 가장 예쁜 개는? → 무지개
- 눈사람이 제일 무서운 계절은? → 봄

**돈·집**
- 금 중에 가장 든든한 금은? → 저금
- 금 중에 가장 아까운 금은? → 세금
- 물가가 오르면? → 내복
- 통장을 스쳐 지나가는 것은? → 월급

**동물·그 밖**
- 고래가 화나면? → 고래고래
- 하마가 큰일 날 뻔하면? → 하마터면
- 오리가 얼면? → 언덕
- 소가 이기면? → 우승
- 소가 웃으면? → 우하하
- 왕이 궁에 들어가기 싫으면? → 궁시렁궁시렁
- 시계가 시치미를 떼면? → 시침 뚝
- 동생이 형 말을 잘 따르면? → 형광펜
- 세상에서 가장 빠른 새는? → 눈 깜짝할 새
- 키우는 돌은? → 반려암
- 우리나라에서 바람이 제일 많이 부는 곳은? → 분당 【확인】
- 다람쥐가 가장 좋아하는 운동기구는? → 쳇바퀴 (다람쥐 코치 앞에서)

**아재 개그 말고 공감 농담 (너구리 대리·판다용)**
- 「다음에 밥 한번 먹자」의 뜻은? → 안 먹는다
- 「거의 다 왔어」의 뜻은? → 지금 출발했다
- 헬스장에서 가장 많이 쓰는 기구는? → 거울 (다람쥐 코치를 두고)
- 월급날 통장의 수명은? → 사흘
