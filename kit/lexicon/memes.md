# 밈·요즘 말 사전

대사에 요즘 말을 넣을 때 여기서 고른다. 기준은 하나다. **부모 세대 시청자도 알아듣나.** 모르는 말이 나오면 그 컷에서 웃음이 끊긴다.

- 수집: 2026-11-12. 원료와 출처 URL 전체는 `skills/winky-script/references/R-25-memes-raw.md`.
- 근거: 국립국어원 「2025 국어 사용 실태 조사」(15~69세 3천 명)만 세대별 수치가 있다. 나머지 「세대 인지」는 기사·칼럼에서 짐작한 것이다.
- 유효 기간: 밈은 빨리 식는다. **석 달마다 다시 조사한다**(다음 2027-02). 「신선」 칸은 그때 다시 본다.
- 예문은 우리가 쓴 것이다. 혈당 수치·판정·원인이 붙은 예문은 쓰지 않는다(check 15).

## 쓰는 규칙

1. **누가 쓰나가 먼저다.** 요즘 말은 판다와 다람쥐 코치만 쓴다. 곰 아빠는 「낡은 말」을 쓰고 판다가 받아친다. 나머지 인물은 「누구나」 줄만 쓴다.
2. **한 회에 두 번까지.** 밈이 많으면 웃음이 아니라 광고처럼 보인다.
3. **실존 인물 말투(⟨인물⟩ 표시)는 말투만 흉내 낸다.** 이름·얼굴·목소리·방송 화면은 쓰지 않는다.
4. **노래 가사·음원은 쓰지 않는다.** 제목 말장난까지만.
5. 이 사전에 없는 밈을 쓰려면 먼저 이 표에 넣고(뜻·세대·출처), 「뺀 말」 기준에 걸리는지 본다.

## 누구나 (부모 세대도 안다)

| 말 | 뜻 | 예 | 근거 |
|---|---|---|---|
| 고구마 / 사이다 | 답답하다 / 속 시원하다 | 「아 진짜 고구마 백 개 먹은 거 같아.」 | 국어원 2025: 60대도 사이다 50.9%, 고구마 38.9%가 이 뜻으로 쓴다 |
| 미쳤다 (칭찬) | 엄청 좋다 | 「이 김치 미쳤다.」 | 국어원 2025: 응답자 67%가 이 뜻으로 쓴다 |
| 역대급 | 지금까지 중 최고(최악) | 「이번 택배 역대급이다.」 | 오래 쓴 말 |
| 꿀잼 / 노잼 | 재밌다 / 재미없다 | 「아빠 개그 노잼.」 | 오래 쓴 말 |
| 혼밥 | 혼자 밥 먹기 | 「오늘도 혼밥이에요.」 | 오래 쓴 말 |
| TMI | 안 물어본 얘기 | 「TMI인데요, 저 어제 계단 열두 번.」 | 오래 쓴 말 |
| 인싸 | 모임 중심에 있는 사람 | 「여사님 탁구장 인싸시잖아요.」 | 오래 쓴 말 |
| 아아 | 아이스 아메리카노 | 「아아 한 잔이요.」 | 카페 주문 말 |
| 손절 | 관계를 끊다 | 「그 단톡방 손절했어.」 | 오래 쓴 말 |
| 덕질 | 뭔가에 푹 빠지다 | 「아빠 요즘 등산 덕질 중이야.」 | 오래 쓴 말 |
| 무야호 ⟨인물⟩ | 신나서 지르는 소리 | (코치가 회원 한 명 늘었을 때) 「무야호!」 | 「무한도전」(2010) 기억. 문구만 |
| 이븐하게 ⟨인물⟩ | 고르게 | 「계란 이븐하게 익었네.」 | 「흑백요리사」 심사평(2024). 식는 중. 말투만 |

| 말 | 뜻 | 예 | 지금 |

| 현타 | 정신이 번쩍 드는 허무함 | 「네 박스 뜯다가 현타 왔어.」 | 살아 있음 |
| 갑분싸 | 갑자기 분위기 싸해짐 | 「아빠 개그 하나에 갑분싸.」 | 살아 있음 |

| 현생 | 진짜 일상(회사 일) | 「현생이 바빠서 못 봤어.」 | 살아 있음 |

|---|---|---|

| 헬린이 | 헬스 초보 | 「회원님은 헬린이시니까!」 |
| 득근 | 근육 얻기 | 「오늘도 득근!」 |
| 3대 | 스쿼트·벤치·데드 무게 합 | 「선생님 3대 몇이세요?」 |

| 벌크업 | 근육 키우려 많이 먹기 | 코치 본인 얘기로만 |

## 곰 아빠가 쓰는 낡은 말 (쓰면 오히려 아재)

곰 아빠가 젊어 보이려고 한참 지난 말을 쓰고, 판다가 「아빠 그거 언제 적 말이야」 하고 받는다. 낡은 말인 걸 시청자가 알아야 웃기니, 부모 세대도 한 번쯤 들어 본 말만 넣는다.

| 말 | 뜻 | 예 |
|---|---|---|
| 알잘딱깔센 | 알아서 잘 딱 깔끔하고 센스 있게 | 「아빠가 알잘딱깔센으로 했지!」 |
| 그 잡채 | 그 자체 | 「이게 바로 등산 그 잡채!」 |
| 킹받네 | 열받네 | 「허허허! 킹받네~」 |
| 어쩔티비 | 어쩌라고 | (판다가 아빠한테 듣고 굳는다) |
| 중꺾마 | 중요한 건 꺾이지 않는 마음 | 「봉우리 셋, 중꺾마다!」 |

## 뺀 말 (쓰지 않는다)

| 말 | 이유 |
|---|---|
| 영포티, 꼰대, 나일리지, 스머프 할배 | 나이 비하. 시청자 중심층을 겨눈다 |
| 너 T야? | 성격 유형으로 사람을 깎는다 |
| 테무인간, 무지컬, 밤티 | 사람·능력·외모 비하 |
| 엄미새, 존맛탱, 존버 | 욕설이 섞인 말 |
| 계엄 패러디, 트래드와이프 | 정치·성 역할 쟁점 |
| 두바이쫀득쿠키 | 고당 디저트 유행을 띄우는 셈이 된다 |
| 아파트 술게임 | 음주 게임. 노래 제목 말장난까지만 |
| 미성년자가 나온 밈, 실존 인물 사생활 밈 | 2차 사용 자제 |
| 노래 가사 인용 밈(우리 엄마 엄마가~ 등) | 저작권 |
| 낄끼빠빠, 안물안궁, 슬세권 | 비하는 아니지만 부모 세대가 모른다는 칼럼이 있다. 판다가 써도 자막만으로는 안 통한다 |
