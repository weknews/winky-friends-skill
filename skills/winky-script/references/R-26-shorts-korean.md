## 2. 공개된 프롬프트·템플릿 (요지 + 출처, 짧게)

- 스케일메이커 이슬 (zbseKvxTeK8) 【확인】: 기사 링크와 함께 "대본 규칙 9개"를 붙임. 요지는 15~20문장, 첫 문장 질문, 짧게 끊는 반말, 누가 한 말은 따로 한 문장, 실제 이름·사건 제외 후 내 말로 다시 쓰기. 본인 말로는 이 규칙 없이 "대본만 써줘"라고 하면 밋밋한 설명글이 나온다고 함. 그림 프롬프트는 "모든 그림에 같은 스타일 한 줄"을 붙이고 그림 안에 글자를 넣지 않음.
- AI남 박대리 (7CbzCffVWsE) 【확인】: 요지는 뼈대 5개 중 하나 + 주제 + 경험·숫자 하나 + 촬영 방식을 넣는 구조. 핵심 줄은 "근거 없는 수치는 만들지 말고 빈자리는 확인 필요로 비워두기". 40초 넘으면 35초 이내로 줄이고 빠지는 문장을 표시하라는 후속 요청도 씀.
- 조팀장 (Y8eARgBTewQ) 【확인】: 개인 맞춤 설정에 "나는 AI 쇼츠 채널을 운영, 타겟은 시니어, 답변은 사람이 말하는 자연스러운 말투로" 식으로 적어 두는 방식. 프롬프트 원문은 유료·댓글 요청 형태라 여기 옮기지 않음.
- 홍아린 AI (eAiF2RQIjFo) 【확인】: 요지는 "1분짜리 쇼츠 콘티로 짜줘. 다섯 장면, 장면당 15초 이하, 장면마다 화면·대사·효과음·카메라 각도". 캐릭터는 정면·옆·표정 한 장 시트로 먼저 생성.
- 미덕 쇼츠 (GPTERS 상상러) 【확인】: 요지는 "초등학생이 좋아하는 그림체, 10~15줄 대본, 인트로 후킹 강화, 1~3분" 같은 요구를 스킬에 고정, 등장인물 외양은 영문으로 먼저 정의.
- 검색 스니펫 【2차】: Framia 블로그는 "[대상 오디언스]를 위해 [구체적인 개념]을 설명하는 [길이]초짜리 쇼츠를 만들어줘" 같은 빈칸 템플릿을 소개. 원문 열기는 실패(도메인 오류)라 확인 못 함.

## 3. 「AI 티 안 나게 / 재미있게」 하는 구체 방법 (출처 있는 것만)

1. 소재를 먼저 정하고 질문을 하나 세움 (Mirr 【확인】, brunch herbeauty/73 【확인】 — 질문형 결말로 바꾼 사례).
2. 대본 규칙을 명시: 문장 수, 첫 문장 질문, 짧은 반말, 누군가의 말은 따로 한 문장 (스케일메이커 【확인】). 규칙 없이 쓰면 설명글 느낌이 난다는 주장.
3. 말투·채널 맥락을 프로필에 고정 (조팀장 【확인】).
4. 대본을 소리 내어 읽기: 첫 문장 2초 기준(박대리 【확인】), 장면표·길이 맞추기(Mirr 【확인】), 초시계로 원고 길이 재기(디지털마케터 【확인】).
5. 실제 사례 우선: 뉴스 기사 링크로 시작 (스케일메이커 【확인】), 상위 영상의 공통점 분석 (GPTERS 파이프라인 【확인】). 한편 "실제 사연을 먼저 모은다"는 방법은 이번 조사에서 직접 확인된 출처가 없음. 사연 원문 그대로 가져오면 저작권·초상권 문제가 생길 수 있다는 경고는 2차 스니펫뿐이므로 【2차】.
6. 원본 복사 금지, 뼈대만 가져오기 (박대리 【확인】). 기사 출처 표기와 AI 콘텐츠 표시 켜기 (스케일메이커 【확인】).
7. 말투 샘플을 준다: 확인된 출처 없음. 【2차】 tilnote 노트 스니펫에서 "글 샘플, 금지 표현, 문장 길이를 알려주면 결과가 크게 달라진다"는 주장이 있으나 본문은 열지 못함.
8. 검수: 자막 전체 재독, AI 제목을 그대로 쓰지 않기 (박서윤 【확인】).
9. 마지막으로 AI가 고친 장면은 이미지 단계에서 다 고치기 (스케일메이커 【확인】 — 영상 생성 후 이미지를 고치면 토큰·시간이 더 든다).

## 4. 잘 되는 썰 쇼츠의 공통 구조 (근거 있는 것만)

- 첫 문장/첫 3초: 질문으로 시작 (스케일메이커 【확인】, 박대리 【확인】 — "첫 문장으로 붙잡고"). 시니어 썰 예시에서 클로드 대본은 "봉투 하나 놓고 사라진 뒤"처럼 장면으로 초반을 잡음 (조팀장 【확인】, 자동 자막 기준이라 세부는 불확실). 첫 3초를 강조하는 자료는 많지만, 공식 수치는 찾지 못함. "시청자는 평균 10초 미만 주의" 같은 수치는 원출처 미확인이라 【2차】이며 쓰지 않는 것이 안전함.
- 반전·긴장 위치: 반전 지점에 효과음(쿵 같은 임팩트)과 음성 쉼을 다시 배치 (brunch herbeauty/73 【확인】). 중간은 "다음이 궁금하게" (박대리 【확인】).
- 끝: 질문형 결말 (스케일메이커 【확인】: 마지막도 질문으로 끝남. brunch herbeauty/73 【확인】: 질문형 결말로 바꿔 재미가 생김). 박대리는 끝을 "저장하고 싶게"라고 함 【확인】.
- 길이: 썰 대본 기준 15~20문장 (스케일메이커 【확인|문장 수 기준】), 12줄·70~110초 (gpters 미덕 쇼츠 【확인】), 43초·장면 7개 (brunch herbeauty/73 【확인】), 40초 넘으면 35초로 줄이기 (박대리 【확인】), 1분 5장면 장면당 15초 이하 (홍아린 AI 【확인】), 유튜브 쇼츠는 최대 3분 (디지털마케터 【확인】). 권장 길이는 채널·내용마다 다르고 근거가 약한 숫자는 제외.
- 자막 방식: 한 줄씩 나오게, 쉬는 구간은 잘라내기 (스케일메이커 【확인】). 흰 글자 + 검은 테두리, 말하는 단어만 초록 (GPTERS 파이프라인 【확인】). 위아래를 검게 가리고 자막은 쇼츠 UI(아래쪽 가림) 위쪽에 두기 (스케일메이커 【확인】). 한글 글자는 영상 모델에 그리지 말고 편집 단계에서 얹기 (디지털마케터 【확인】).
- 장면 길이: 1초 미만으로 바뀌는 구간은 자동 제거 (GPTERS 파이프라인 【확인】).
- 음향: 효과음으로 리듬을 만들고 말할 때 배경음을 낮춤 (GPTERS 파이프라인 【확인】, brunch herbeauty/73 【확인】).
