# R-19 해외 시트콤 대본 장면 분석 (2026-11-11 조사)

1화 Codex 안의 상담소 장면이 「무슨 소린지 모르겠다, 사람이 생각하는 흐름이 아니다」는 평(제작자 11/11)을 받고 조사했다.
웹 검색 1회, 원문 열람 5회. 대본은 옮기지 않고 구조만 적었다. 대본 원문은 요약 도구로 읽었으므로 대사 인용은 방송본과 대조가 필요하다.

표기: 【확인】 원문 직접 확인, 【2차】 요약·블로그 경유, 【추정】 판단, 【미확인】 찾지 못함.

## 1. Seinfeld 「The Marine Biologist」 끝 장면 (지난 일 되짚기 + 회수)

출처: https://www.seinfeldscripts.com/TheMarineBiologist.htm 【확인, 요약 도구 경유】

- 사건(고래 구조)은 화면에 나오지 않는다. 다음 장면 식당에서 George가 직접 다시 말한다. 20줄 안팎이다.
- 듣는 사람들이 끼어든다. Jerry가 낱말을 고쳐 주고 George는 「아무튼」 하고 넘긴다. Kramer의 「그래서 어떻게 했어?」가 이야기를 꼭대기로 민다.
- 꼭대기에서 George는 말하지 않고 주머니에서 골프공을 꺼낸다. Jerry와 George가 Kramer를 본다. Kramer의 한마디로 터진다.
- 골프공은 앞에서 두 번, 지나가는 말과 동작으로만 심었다(트렁크의 공 600개 자랑, 주머니를 뒤지다 떨어뜨림). 심을 때 강조하지 않았다.
- 터진 뒤 장면은 조금 더 간다. 마지막 줄은 새 농담이 아니다. George 몸에 남은 모래 이야기다.

## 2. Friends 4x01 「The One with the Jellyfish」 (추궁 → 자백)

출처: https://www.friends-tv.org/zz401.html 【확인, 요약 도구 경유. 팬 전사본】

- 셋이 해변에서 돌아온다. 한 명이 「말 안 한다」고 버티고, 듣는 쪽이 계속 묻는다. 버티던 사람이 먼저 못 참고 턴다.
- 사실은 순서대로 한 겹씩 나온다. 쏘였다 → 집이 멀었다 → 걸을 수 없었다 → 그래서 무엇을 했는지. 부끄러운 대목은 맨 끝이고, 듣던 사람이 먼저 알아채 입 밖에 낸다.
- 셋 다 자기에게 유리하게 말한다. 한 명은 나서려 했다고 하고, 한 명은 자기가 피해자라고 하고, 한 명은 남 일처럼 말한다. 사건 보고가 인물 대사가 된다.
- 【미확인】 이 회의 엔딩 꼬리 장면. 전사본에 따로 적혀 있지 않았다.

## 3. Malcolm in the Middle 1화 (화면에 대고 말하기 + 꼬리)

출처: https://jillgolick.com/2007/11/malcolm-in-the-middle-pilot 【2차, 작가 블로그 분석】, https://coffee-for-two.com/2023/08/29/golden-words-malcolm-in-the-middle-pilot/ 【2차】

- 처음과 끝에서 Malcolm이 화면을 보고 말한다. 내용은 대체로 상황 정리지만 끝은 자기 생각 한 줄로 맺는다.
- 끝 꼬리: Malcolm이 일이 어떻게 됐는지 화면에 대고 정리하는 동안 동생 목소리가 밑에서 계속 들린다. 카메라가 물러나면 Malcolm이 엎어 놓은 쓰레기통 위에 앉아 있고 동생이 그 안에 있다. 정리하는 말이 그대로 마지막 개그가 된다.
- 화면에 대고 하는 말이 장면을 멈추지 않는다. 장면 안의 일은 계속된다.
- 【미확인】 장면 중간 독백의 길이, 장면으로 돌아오는 방식.

## 4. 뽑은 규칙 (【추정】 1~3절에서)

| # | 규칙 | 근거 장면 |
|---|---|---|
| 1 | 지난 일은 본 사람이 다시 말한다. 듣는 사람이 짧게 밀어 준다. 사실은 한 번에 하나씩, 부끄러운 것이 맨 끝에 나온다 | 1절, 2절 |
| 2 | 말하는 사람은 자기 사정(억울함, 자랑)부터 말한다. 핵심은 그 말에 딸려 나온다 | 2절 |
| 3 | 회수할 것은 앞에서 지나가듯 심는다. 꺼낼 때는 설명하지 않는다. 그다음은 다 같이 한 사람을 보는 정적이고, 한마디로 닫는다 | 1절 |
| 4 | 화면에 대고 하는 말은 짧게 하고, 그동안 장면 안의 일이 이어진다 | 3절 |
| 5 | 꼬리는 새 농담을 만들지 않는다. 사건이 남긴 것 하나를 보여 준다 | 1절, 3절 |

1화 7판 적용: 13~17번(규칙 1~3), 21~24번(규칙 4·5). `episodes/ep01-fruit-juice/script-9c.md` 「해외 대본에서 가져온 규칙」 표.
