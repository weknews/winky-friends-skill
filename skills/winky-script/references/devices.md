# 회차를 고르는 메뉴 (웃음 장치 · 지침 전달 경로 · 결말 · 비트 시트 · 자동 탈락)

대본 스킬 ②~⑤단계에서 쓴다. 메뉴는 고르라고 있는 것이지 다 쓰라고 있는 것이 아니다. 한 회에 웃음 장치는 하나가 중심이고, 많아야 둘이다.

원칙(content-studio `05-concept-methods.md` C-1): **다양성은 운에 맡기지 않는다.** 축을 먼저 펼치고, 장부(`episodes/LEDGER.md`)의 직전 3편과 조합이 겹치지 않게 고른다.

## 1. 웃음 장치

| 장치 | 뜻 | 씨앗 예(`rules/world.md` 6절) | 낙인 주의 |
|---|---|---|---|
| **셈 키우기** | 같은 핑계를 세 번, 점점 크게 | 주스 세 잔(ep01) | 이미 ep01이 썼다. 직전 3편에 있으면 고르지 않는다 |
| **엇갈림** | 둘이 같은 말을 서로 다른 뜻으로 알아듣는다 | 「당 0%」를 사장은 「설탕 0」, 판다는 「칼로리 0」으로 | 오해한 쪽을 바보로 그리지 않는다. 둘 다 그럴 만했다 |
| **체면** | 원하는 걸 직접 말 못 해 남의 입을 빌리거나 버틴다 | 회장님 건배사, 공구 열두 상자 | 체면이 과녁이다. 병이 과녁이 아니다 |
| **말 전하다 틀어짐** | 윙키가 말을 옮기며 조금씩 바뀐다 | 선생님의 「일반적으로는요」가 3층에선 「괜찮대요!」 | 마지막에 원래 말로 돌아온다. 선생님이 틀린 게 아니다 |
| **맞수** | 둘이 서로 자기가 맞다고 증인을 부른다 | 거북 여사 경력 vs 다람쥐 코치 센서 | 둘 다 반은 맞는다. 한쪽만 지지 않는다 |
| **단톡 실수** | 잘못 보낸 톡, 퍼 나른 「좋은 정보」, 읽씹 | 곰 아빠 「좋은 정보 공유합니다^^」, 도치 새벽 링크 | 정보를 퍼 나른 사람이 아니라 정보 홍수가 과녁이다 |
| **지위 역전** | 늘 맞던 사람이 틀리고, 늘 틀리던 사람이 맞는다 | 판다가 틀리고 곰 아빠가 바로잡는 회 | 당뇨인이 늘 틀리는 편성을 깨는 데 쓴다 |

## 2. 지침 전달 경로 (`rules/world.md` 3절)

| 경로 | 모양 | 언제 |
|---|---|---|
| **현장 한 줄** | 선생님이 자기 볼일로 그 자리에 있다가 「…하나만입니다.」 | 선생님이 있을 이유가 있을 때(층간소음, 카페, 분리수거장) |
| **상담소 풀이** | 컷 아웃 뒤 상담소에서 윙키가 묻고 선생님이 이유 한 줄 | ep01이 썼다. 직전 3편에 있으면 다른 경로 |
| **윙키 보고** | 선생님은 본편에 없다. 윙키가 「선생님, 3층에서요!」 | 이야기가 선생님 없는 곳(계단, 옥상)에서 끝날 때 |
| **우편함 쪽지** | 선생님이 못 다 한 답을 쪽지로. 다음 날 그 집에서 읽는다 | 당사자 혼자 정리할 시간이 필요할 때(체면 장치와 잘 맞는다) |
| **근거 자막만** | 인물 누구도 해설하지 않는다. 위 근거 자막 띠 한 번 | 상황 자체가 답을 보여 줄 때 |

어느 경로든 지침 한 줄은 **한 번, 짧게**. 원문은 근거 자막·끝 화면·설명란에 둔다.

## 3. 결말 유형

| 결말 | 모양 | 낙인 점검 |
|---|---|---|
| **본인 선택** | 틀린 사람이 스스로 고른다(ep01 「오늘은 사과로 줘.」) | 기본형. 주변은 말하지 않는다 |
| **같이 바꾸기** | 걱정하던 사람도 자기 몫을 바꾼다(판다도 같이 덜 산다) | 가족이 감시자가 아니라 같은 편이 된다 |
| **엇갈린 채 끝** | 오해는 풀렸는데 다른 데서 또 엇갈린다(다음 소동의 씨앗) | 틀린 사람이 당뇨인이 아닐 때 쓰기 좋다 |
| **회수** | 첫 장면의 소품·말로 돌아와 한 방에 닫힌다 | 소품이 누군가를 들킨 증거로 쓰이지 않게 |
| **떡밥 남김** | 고정 떡밥(검진 봉투, 엘리베이터 안건)을 한 칸 움직이고 끝 | 이야기는 그 회에서 닫혀야 한다. 떡밥만 남는다 |

## 4. 비트 시트 (모양이 다른 넷)

길게 베끼라고 둔 것이 아니다. 「이런 모양도 된다」를 보여 준다. 초는 대략이다.

**A. 셈 키우기 + 상담소 풀이 + 본인 선택** (ep01 「주스 세 잔」, 전체는 `example-ep01.md`)
1. 0초 판다가 착즙한 주스를 내민다. 곰 아빠 「설탕 안 탔지? 안 적어도 되겠네~」
2. 둘째 잔 「두 잔이 한 잔이지.」 셋째는 말 없이 빈 잔 셋
3. 다음 날 상담소. 윙키가 편들다 「주스만 세 잔이요!」
4. 선생님 「치죠.」 곰 아빠가 기록장 「한」→「세」
5. 그날 저녁, 곰 아빠 「오늘은 사과로 줘.」 윙키가 꺼낸 컵 셋을 도로 민다

**B. 맞수 + 현장 한 줄 + 둘 다 반만 맞음** (씨앗 7, 옥상 평상)
1. 0초 평상. 거북 여사가 혈당 측정기를 꺼내는 손, 다람쥐 코치가 팔 센서를 툭 친다(화면 숫자 없음)
2. 「15년을 쟀어.」 「요즘은 붙여요.」 내기가 붙는다
3. 둘 다 계단을 내려가 상담소 문을 두드린다. 선생님은 얼음 대야에 발을 담그고 있다
4. 「누가 맞아요?」 선생님 「…재는 법, 가끔 다시 배우는 거. 하나만입니다.」
5. 둘이 동시에 서로를 본다. 다음 장면, 둘이 나란히 앉아 설명서를 읽는다. 여사가 코치 센서 사용법을 고쳐 준다

**C. 말 전하다 틀어짐 + 윙키 보고 + 회수** (씨앗 2, 카페와 택배)
1. 0초 카페 입간판 「당 0%」. 판다 「이거 몇 잔 마셔도 돼요?」 사장 「좋은 거예요~」
2. 윙키가 선생님께 묻고 「일반적으로는…」까지 듣고 뛰어나간다
3. 2층에선 「괜찮대요!」, 3층에선 「많이 마셔도 된대요!」 계단마다 말이 커진다
4. 판다가 상자째 주문한다. 택배 선반이 막힌다
5. 윙키가 내려와 선생님 말을 끝까지 듣는다. 근거 자막 한 번. 윙키가 계단을 거꾸로 오르며 「…일반적으로는요!」를 층마다 다시 말한다

**D. 단톡 실수 + 우편함 쪽지 + 같이 바꾸기** (곰 아빠 「좋은 정보^^」)
1. 0초 단톡방 알림음. 주민들이 동시에 휴대폰을 뒤집는다
2. 곰 아빠가 퍼 나른 「혈당에 좋은 ○○즙」 링크. 판다가 읽고 바로 열두 상자를 시킨다(손이 크다)
3. 곰 아빠는 딸이 산 걸 거절 못 하고, 딸은 아빠가 보낸 거라 믿는다. 서로 상대가 원하는 줄 안다(엇갈림)
4. 다음 날 아침 우편함에 선생님 쪽지 한 장. 둘이 같이 읽는다. 근거 자막
5. 둘이 남은 상자를 들고 계단에 선다. 판다 「…반품하자.」 곰 아빠 「허허, 그게 말이지」 그리고 같이 웃는다

## 5. 자동 탈락 (로그라인 단계에서 바로 거른다)

| # | 탈락 | 확인 |
|---|---|---|
| X1 | **음식만 바꿔 끼워도 성립한다** | 오해 낱말(주스→고구마→시리얼)을 다른 음식으로 바꿔도 대본이 그대로면 ep01 복제다 |
| X2 | 장부상 직전 3편과 축이 3개 이상 같다 | 틀리는 인물·장소 순서·웃음 장치·전달 경로·결말 중 |
| X3 | 지침 관문을 못 넘는다 | 지침에도, 지침 밖 근거에도 문장이 없다 |
| X4 | 당뇨인 인물이 또 틀린다 | 직전 회에 틀린 사람이 당뇨인이었는데 이번에도 당뇨인이 틀린다 |
| X5 | 들킨 환자 구조 | 추궁 → 자백 → 혼남으로 읽힌다 |
| X6 | 첫 3초가 설명이다 | 사건·충돌·소리가 아니라 설명으로 연다 |
| X7 | 웃음이 병·몸·식탐에서 나온다 | `rules/stigma.md` |
| X8 | 곰 아빠 쏠림 | 곰 아빠가 중심 인물인 회가 장부상 직전 3편에 이미 1편 있다 |

LLM 판정은 이 표 같은 규칙 검사에만 쓴다. **재미는 사람이 고른다.** 지금 그림이 있느냐는 탈락 이유가 아니다(대본이 먼저, 그림은 따라온다).
