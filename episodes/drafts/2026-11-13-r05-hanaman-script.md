# 윙키와 친구들 · 모래언덕 빌라 「하나만요」 대본 2판 (2026-11-13, 초안)

- 대사: `episodes/drafts/2026-11-12-real-r05-dialogue.md` 3판(미르님 승인 2026-11-13). 2판에서 손본 줄은 아래 「2판에서 바꾼 것」에 있다. **이 파일이 대사 파일보다 앞선다.**
- 트리트먼트: `episodes/drafts/2026-11-12-real-r05-treatment.md`. 근거 칸: `kit/evidence/k-family-screening.md`.

## 4판에서 바꾼 것 (미르님 검수, 2026-11-16)

- 18·19번 「진료 3분이에요 / 하나만 고르세요」 → 「그럼요, 다 물어… / …궁금한 거부터요」. 선생님은 다 물어봐도 된다고 하다가 열두 줄 쪽지에 기겁한다. 「하나만」은 판다가 줄인 말이 된다.
- 윙키 단역: 분리수거장 넓은 컷(14·16·17·20·24) 뒤에서 택배 상자를 나른다. 대사 없음, 24번 「따님은 검사」에 놀라 돌아본다(`winky-상자-평온`·`winky-상자-놀람` 새로).

## 2판에서 바꾼 것 (Fable 디렉터 검수, 2026-11-13)

판정은 「고치고 그림 단계」였다. 구조는 그대로 두었다.

| 지적 | 2판 |
|---|---|
| 쪽지가 둘(종이·폰)이고, 저녁에 판다 손에 있던 쪽지를 대기실에서 아빠가 꺼낸다 | **종이 쪽지 한 장으로 잇는다.** 아침에 아빠 주머니 → 저녁에도 주머니에 삐죽(4·5번, 시청자가 판다보다 먼저 안다) → 판다가 뽑아 편다(8번) → 분리수거장에서 판다가 내밀고(17번) 아빠 손으로 넘어간다(20번) → 아빠가 연필로 긋는다(22번) → 아빠가 쥔 채(28번) → 대기실에서 아빠가 내민다(33번) |
| 「진료 날 → 다음 날 → 수요일 → 금요일」이면 한 주에 진료가 두 번 | 「아빠 진료 날 아침」 → 「그날 저녁」 → 「다음 날」 → 「진료 이틀 전 밤」 → 「다음 날」 → 「아빠 진료 날」. 대사 「금요일에」 → 「모레」 |
| 반전 위 근거 자막이 설교가 된다 | 26번 근거 자막 삭제. 근거는 끝 화면에만 |
| 자막 1.2초 미만 컷 여섯 | 대사 컷은 1.4초 이상(목소리·자막 1.2초 이상) |
| 이름표 「퇴근함」을 못 읽으면 15번이 안 웃긴다 | 14번 1.6초, 이름표가 15번까지 이어진다 |
| 첫 컷·마지막 컷이 짧다 | 1번 2.0초, 35번 3.0초 |
| 번호표가 판다 손이라 누구 진료인지 모호 | 번호표는 곰 아빠 손 |
| 「아 진짜!」(원 플러스 원 뒤)가 25번과 같은 반응 | 삭제 |
| 「…아버님 괜찮으세요?」 | 삭제. 판다가 먼저 이유를 말한다 |
| `boing`이 「여기서 웃어라」로 들린다 | 삭제 |
| 「금요일 반차요」 「이번엔 제 검사요」는 상사에게 잘린 말 | 「실장님, 반차 좀 쓸게요. / 아빠 병원 따라가려고요.」 「실장님, 반차 하나만 더요. / 이번엔 제 검사 받으려고요.」 |
| 「금요일에 아빠 따라가는데요,」 어디를 따라가나 | 「모레 아빠 병원 가요.」 |
| 「근데 따님은요?」는 잘라 낸 말 | 「근데 따님은 검사 받아 봤어요?」 한 줄 |
| 「원 플러스 원은?」 | 「원 플러스 원은 안 되냐?」(아빠 말투) |
| 곰 아빠 카드 「진료에는 개그를 붙이지 않는다」와 3·5·21번 충돌 | 미르님 결정 A: 허용. 개그 대상이 수치·병이 아니라 「진료 얘기를 피하는 아빠」다. 카드 문구를 「진료·약·수치 자체를 개그 소재로 쓰지 않는다」로 고쳤다 |

도치의 셈 「세 번째… / 네 번째…」는 되살리지 않는다(화면에 없던 반차를 세는 줄이고, 「다음엔 나도 같이 가」와 어긋난다).

## 고른 이유

- **출발 장면:** 네이트판 공개 글 r05(30대 딸, 엄마 혼자 진료 가면 아무것도 안 묻고 나온다), r07·r08·r11. 요약만, `kit/moments/real-nate-2026-11.md`.
- **잘못된 확신:** 판다 「나는 보호자지, 검사 대상이 아니다.」(당뇨 없는 인물이 틀린다)
- **그래서 사슬:** 미르님이 「하나만요」를 골랐다(「훨씬 좋아졌다, 이 방식으로 가자」). AI가 지어낸 사슬 3안은 폐기했다(`studio/archive/2026-11-12-chains.json`).
