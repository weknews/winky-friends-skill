| 파일 | 내용 |

| `KIT-SPEC.md` | 제작 키트 사양 1판(크기 레지스트리 mm, 세트·카메라, 자세·표정, 소리, 글자, 자동 검사 12항). 5절 음악 큐 규칙 1~4는 `music.md`가 대체한다 |
