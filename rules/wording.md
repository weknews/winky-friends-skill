# 대사·화면 문구 점검

## 1. 구어체 (대사)

기준은 하나다. **한국 사람이 이 상황에서 정말 이렇게 말하나.** 대본마다 「대사 점검」 표(# · 대사 · 점검)를 두고 한 줄씩 소리 내 읽는다.

- 번역투 금지: 「제가요!」 → 「제가 따라 드릴게요!」, 「칩니다.」 → 「치죠.」.
- 설명하는 말 금지: 「2층, 택배요!」 → 「택배요!」.
- 관계에 맞는 말투: 딸→아빠 반말, 알바→어른 「~요」, 어른→아이 「먹어라」.
- 조사·준말은 입말대로: 「주스에는」 → 「주스엔」.
- 「~」로 끝나는 음절은 늘여 읽는다(엔진이 0.18초 늘인다).
- 한 줄 14자 이하(공백 빼고), 한 컷 대사 한 줄, 자막 1.2초 이상, 초당 5음절 이하(엔진 check 9번이 잰다).
- 승인된 대사는 한 글자도 바꾸지 않는다. 바꿀 때는 판 이력에 적는다.

## 2. 화면 문구

화면에 나오는 모든 글(이름표, 상자 라벨, 칸 글자, 「다음 날」, 근거 자막, 끝 화면, 썸네일)을 「한국 사람이 실제로 이렇게 쓰나」로 본다. 제작 기록에 「화면 문구 점검표」(자리 · 원문 · 고친 말 · 이유)를 남긴다. 예:

- 「당뇨 2형」 → 「2형 당뇨」(분류표 어순 → 우리말 어순).
- 「과일주스의 당도 유리당」 → 「당은」(「당도」가 糖度로 읽힌다).
- 「의학 검수 위뉴 의료진」 → 「의학 검수: 위뉴 의료진」(항목·값을 쌍점으로 나눈다).
- AI 표시는 근거 목록 끝에 붙이지 않고 따로 한 줄.

## 3. 이름 체계·제목·썸네일

- 시리즈: **「윙키와 친구들 · 모래언덕 빌라」**. 「윙키와 친구들」이 제목(크게), 「모래언덕 빌라」가 부제(무대 이름, 작게).
- 회차 제목은 **번호 없이** 이름만(「주스 세 잔」). 「1화」를 화면·썸네일·HTML 제목 어디에도 쓰지 않는다. 개인화 서빙이라 보는 순서가 사람마다 다르다(check 11번).
- 로고(`kit/logo/logo-main.png`)는 **썸네일에만** 쓴다. 본편에는 로고도 제목 글자도 넣지 않는다(check 11번).
- 썸네일 훅 = **그 회의 오해를 묻는 질문**: 「과일주스는 건강식이니까 / 괜찮다?」. 위 작은 띠는 「당뇨 오해 바로잡기」. 끝을 올려 되묻는 말투로, 답은 쓰지 않는다.
- 게시물 설명란: 제목 → 바로잡는 사실 두세 줄 → 「얼마나 ~는 담당 선생님과」 → 근거 → 검수 표기 → AI 표시 → 「일반 건강 정보이며 진료를 대신하지 않습니다」.
